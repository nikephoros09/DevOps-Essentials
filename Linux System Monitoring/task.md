# Linux System Monitoring 

## Описание проекта

 Данные скрипты предназначен для автоматизации задач системного администрирования. Они разделены на пять модулей, решающих задачи от базовой валидации входных данных до проверки использования дискового пространства и парсинга системных конфигураций.

---

## Возможности

* **Сбор системных метрик**

  * IP-адрес
  * Маска подсети
  * Gateway
  * Общий, используемый и свободный объём RAM
  * Используемое дисковое пространство `/`
  * Системный uptime

* **Экспорт отчётов**

  * Генерация снимка состояния системы.
  * Сохранение отчёта в лог-файл формата `DD_MM_YY_HH_MM_SS.status`.

* **Гибкая визуализация**

  * Настройка цветов текста и фона через аргументы командной строки.
  * Загрузка цветовой схемы из внешнего конфигурационного файла `.conf`.

* **Глубокий анализ файловой системы**

  * Подсчёт общего количества папок и файлов, включая вложенные.
  * Группировка файлов по типам:

    * конфигурационные файлы;
    * текстовые файлы;
    * лог-файлы;
    * архивы;
    * исполняемые файлы;
    * символические ссылки.
  * Поиск топ-5 самых тяжёлых каталогов.
  * Поиск топ-10 самых тяжёлых файлов.
  * Поиск топ-10 исполняемых файлов с автоматическим вычислением MD5-хеша.
  * Измерение времени выполнения анализа.

## Структура проекта

```text
.
├── 01/             # Валидатор текстовых аргументов
│   └── main.sh
├── 02/             # Сбор системной информации и экспорт в файл
│   └── main.sh
├── 03/             # Цветовое форматирование через аргументы CLI
│   └── main.sh
├── 04/             # Визуализация с поддержкой config.conf
│   ├── main.sh
│   └── config.conf
└── 05/             # Анализ и аудит файловой системы
    └── main.sh
```

## Требования и установка

### Системные требования

* **ОС:** Linux (Debian, Ubuntu, RHEL, CentOS или аналогичные дистрибутивы).
* **Оболочка:** Bash версии 4.0 или выше.
* **Утилиты:** `coreutils`, `awk`, `sed`, `grep`, `find`, `net-tools` или `iproute2`.


---

## Использование

### Часть 1. Валидация ввода (`01/`)

Скрипт принимает один текстовый параметр. Если передано число, выводится ошибка.

```bash
cd 01
bash main.sh "Hello World"
```

---

### Часть 2. Мониторинг системы и сохранение отчёта (`02/`)

Скрипт выводит ключевые метрики операционной системы и предлагает сохранить результат в файл.

```bash
cd 02
bash main.sh
```

После вывода данных введите `Y` или `y`, чтобы сохранить отчёт в текущую директорию.

---

### Часть 3. Визуальная кастомизация через CLI (`03/`)

Настройка цветового оформления вывода осуществляется с помощью четырёх числовых параметров в диапазоне от `1` до `6`.

```bash
cd 03
bash main.sh 1 3 4 5
```

Цветовая гамма:

| Значение | Цвет       |
| -------: | ---------- |
|      `1` | Белый      |
|      `2` | Красный    |
|      `3` | Зелёный    |
|      `4` | Синий      |
|      `5` | Фиолетовый |
|      `6` | Чёрный     |

---

### Часть 4. Конфигурирование через `.conf` (`04/`)

Скрипт автоматически загружает цветовую схему из файла `config.conf`.

Если какой-либо параметр не задан, применяется тема по умолчанию.

#### Конфигурационный файл

Настройте файл `04/config.conf`:

```ini
column1_background=2
column1_font_color=4
column2_background=5
column2_font_color=1
```

#### Запуск

```bash
cd 04
bash main.sh
```

---

### Часть 5. Анализ файловой системы (`05/`)

Скрипт принимает путь к директории, который **обязательно должен заканчиваться символом `/`**, и выводит подробную статистику по файлам и каталогам.

```bash
cd 05
bash main.sh /var/log/
```
